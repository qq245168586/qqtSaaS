# 送货汇总与客户对账

入口：供应链 → 送货汇总。默认视图为「销售明细（对账）」。本次只在本地运行，不发安装包、不部署服务器。

2026-10-06 后续：用户已要求发布 App 更新，该功能纳入 Windows 2.1.16，继续使用现有线上 API。

## 筛选

- 公司可选全部、天美意、趣趣特；客户可多选，也可输入客户名称关键词（例如「御牛纪」覆盖其门店）。
- 只选客户时，跨两家公司按送货单保存的客户名称匹配，不受两个公司客户 ID 不同的影响。公司加客户取交集，多客户之间为并集。
- 日期按送货日期，包含首尾两天；保留客户分类、按客户/分类/产品/单据汇总。
- 搜索客户、单号或商品支持中文、拼音、首字母，匹配后保留整张送货单，不截掉其他商品。
- 仅统计正式送货单，包括未打印的正式单；排除草稿，API 已排除删除记录。关联零售任务的正式送货单仍参与客户对账；这是送货对账，不是总览收入，收入防重复统计规则不变。

## 2026-10-07：恢复两张 Sheet 的 Excel 导出

用户明确：两家公司各自独立，每个公司文件都包含「汇总」「明细」两张 Sheet；继续精简内部字段。当前导出按钮已改为「导出对账 Excel（汇总＋明细）」，替代旧的 CSV 导出。

- 选全部公司时生成两份独立 `.xlsx`，只为有筛选结果的公司生成文件；选单一公司时生成一份。每份分别选择保存位置，取消的文件不提示保存成功。
- 固定第一张「汇总」按客户归并，第二张「明细」列所有商品行；不随屏幕的按产品/分类/单据视图改变导出合同。
- 汇总保留客户名称、销售数量（按单位）、销售单价、金额。销售单价沿用原汇总的加权平均含义；单位混用或数量为零时留空，不虚构平均单价。不同单位不相加。
- 明细保留单据日期、单据编号、客户名称、商品名称、规格、单位、数量、单价、金额、单据金额、备注。按日期＋单号排序，保留同单商品顺序。
- 直接对照用户提供的趣趣特/天美意御牛纪202608原文件，复用保留列的列宽、标题行30磅、默认行高15磅、等线11号、灰色表头、细边框、两行合并标题/条件和数字格式。规格/备注为新增保留字段，宽度取原客户商品名称/客户列；条件行因合并单元格无法自动适配，增加高度以显示公司和期间。精简后列数自然减少，不恢复已删的税务/审核/编码等内部列。
- 金额和数量写入真实 Excel 数值；名称、单号、日期、备注为文本，不执行公式。按保存的送货单金额核对汇总，不读取金蝶商品库或零售金额。
- 明细页最后一行同时保留商品金额合计和单据金额合计，原始差额不抹平。客户小计放在汇总 Sheet，不追加到明细表尾混在一起。
- 使用按需加载的 ExcelJS，仅点击导出时载入；复用现有文件保存 IPC，不新增服务器接口或改生产数据库。

## 原 CSV 对账内容（2026-10-06，实现保留但界面已改为 Excel）

参考用户提供的御牛纪、柏希酒店、星星之家、一乐 Excel 的「标题 → 期间条件 → 商品明细 → 合计」结构。CSV 保留 UTF-8 BOM、中文标题、筛选条件、公司、送货日期、单号、客户、商品名称、规格、单位、数量、单价、商品金额、单据金额、备注。

不导出审核状态、修改/审核时间、商品编码、内部人员/仓库、金蝶税务/应收字段。CSV 本身不支持颜色、合并单元格或列宽。

单据金额来自送货单 total_amount，每张单仅计一次；明细行优先保留数据库 amount，旧数据未提供 amount 时才用数量×单价（两位小数）补算。不会读取金蝶商品名、价格或重新匹配商品，也不使用总览的零售任务金额。

同单多商品时，单据金额只出现在第一行，后续为空，避免参考表中重复成交总额导致累加重复。保存金额与商品明细不一致时保留原值并提示差额；导出同时有商品明细金额合计和单据对账总额。

导出完整筛选结果，包括屏幕分页外的行；结尾列各公司各客户小计、公司合计、对账总额。不同单位的数量分开显示，不把斤、克、个相加。全部公司可合并导出但公司列和小计独立；选单一公司则导出该公司的客户对账。

## 技术与验证

- TypeScript strict，decimal.js 计算，RxJS + reducer 保存筛选和报表快照。
- 使用现有 `/delivery-notes`、`/customers`、`/customer-categories` API，完整读取日期范围内分页；不新增服务端依赖，不改源单据/商品。
- 报表读取独立 schema 保留 amount，不改变送货单编辑/提交合同。
- 日期无效、数据缺失/非法、分页重复/不完整/总数变化、离线或加载中均阻止导出，避免静默产生缺单金额。
- CSV 双引号/逗号/换行转义；文本公式注入防护；数值负数仍为数值。
- 单元测试：公司客户交集、跨公司客户、金额不重复、存量金额与舍入、赠品、数量单位、分类及旧汇总视图、拼音、CSV 内容与注入防护、日期、完整分页。
- 隔离 Electron 联调：103 条跨页记录，客户跨公司 101 张正式单全量导出，叠加公司后只有 1 张，排除草稿，不写生产环境。
