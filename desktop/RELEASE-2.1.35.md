# 2.1.35

发布日期：2026-11-27。

- 零售任务汇总支持直接编辑订单名称、交付时间、订单金额、负责人、优先级，以及展开后的商品、地址、订单详情和备注。
- 支持 Enter 保存、Tab 切换下一格、Esc 取消；保存失败保留输入并可重试，保存后刷新数据不清空表格。
- 增加列宽拖动、60%–150% 缩放、适应宽度、全屏编辑和本机布局记忆。
- 可以撤销最近的单格修改；服务器校验原值，遇到同一字段已被其他人修改时提示冲突，避免覆盖。
- 手动新增和完整编辑订单使用页面内表单，保存和取消按钮置于表单顶部；AI 草稿仍需用户确认。
- 运费与订单金额独立编辑，收入汇总仍仅统计订单金额。

单格保存接口已部署到生产服务器，未新增数据库字段或更改历史业务数据。本版沿用 2.1.34 的更新助手、设备识别及错误诊断。
