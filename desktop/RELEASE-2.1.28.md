# 2.1.28 发布说明

发布日期：2026-11-01

- 点击“重启更新”后，独立更新助手等待 App 退出，使用 `/S --updated --force-run` 在后台安装，成功后自动打开 App。
- 新安装包收到旧客户端的 `--updated` 参数时也进入静默模式，兼容 2.1.27 的更新启动方式。
- 首次手动安装仍使用正常向导；不跳过 Windows 安全确认，不修改 SmartScreen 设置。
- 安装助手等待安装程序退出并记录非零退出码；保留失败日志及手动安装入口。
- 普通退出不自动触发安装，仍由用户主动点击“重启更新”。

验证：类型检查、生产构建及 93 项测试通过；NSIS 编译检查旧客户端静默分支。尚未进行 Windows 实机安装验证。

本版尚未配置正式 Authenticode 代码签名，Windows“未知发布者”或 SmartScreen 提示需要另行申请受信任的代码签名证书、接入打包签名及时间戳。静默安装不会绕过这些系统安全提示。
