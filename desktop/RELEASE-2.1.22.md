# 2.1.22 发布说明

新增“周期合规与留底”入口，嵌入服务器的 `/compliance/` 工作台。导航显示红点：有到期周期或未打印签字表时提示处理。

工作台支持：60 项首次待执行、逐项日/周/月/年周期、完成本期自动创建下一期、阻塞原因、不可覆盖的 A4 签字表、明确打印确认、签字照片压缩到 1 MB、5 GB 总配额、档案/照片手动删除及两年前筛选。

默认周期是可编辑的内部管理建议；操作型事项按每次实际作业留痕并每日汇总提醒，管理项按周/月/年复核。不会把所有检查项写成每日法定检查。

安装包：`TMY-TRI-Manager-2.1.22-x64-Setup.exe`。构建后的 SHA-512：

`2393b3bf2efeaf0595d7b9830501a5d28b9ed7c1d9a28c209a6c49917d539266d15b4c69128961506a14c42318de9f89c3b22cf9703cc94bd7265a7b6a50045e`

已发布至 Windows 稳定更新源，安装包、blockmap 先就位，最后原子切换 `latest.yml`；旧 2.1.21 安装包及旧更新清单均保留。安装包大小为 111825067 字节。

Electron 实际界面验证通过：使用隔离测试配置启动 App，导航显示合规红点，App 内嵌的线上工作台展示 60 项及周期列表，无 renderer 脚本错误。测试仅读取生产数据，不生成测试档案或打印任务。

未在 Windows 实机安装或实体打印机上进行验收。

公网验收：`latest.yml` 返回 2.1.22，安装包与 blockmap 均为 HTTP 200，安装包 Content-Length 与清单一致；实际 HTTP Range 下载的 4096 字节与本地已校验安装包对应位置逐字节一致。完整 HTTPS 下载校验超过 120 秒服务器命令时限，因此完整校验使用发布目录中安装包的 SHA-512。
