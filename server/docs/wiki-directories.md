# Confluence 目录分类

使用 `/wiki/directories` GET 列表、POST `{path}` 新建。规范路径以 `/` 开头，用 `/` 分层。根目录 `/` 表示未分类，为虚拟目录；多级路径会自动写入各级目录。`wiki_directories.path` 唯一，二进制校对避免路径误合并。路径仅用于分类，不用作文件系统访问。

文档表 `wiki_pages.directory_path` 保存完整路径、默认 `/`，具有目录及删除状态联合索引。迁移保留原有内容，旧文档自动归根目录。目录层级最多8层，每级80字、总长500字，禁止 `.`、`..`、反斜杠和控制字符。不存在的目录不能保存；文档变更仍校验版本以避免覆盖同事修改。

左侧展示目录及原有页面/子页面；选择目录后新建文档默认归该目录，编辑已有文档可修改保存目录。文档父子关系独立于分类，跨目录的子页在所属目录作为顶层页面展示。恢复历史版本只恢复正文、标题、图标，不改当前目录。暂不提供目录重命名、删除或批量移动。

网页版与 App 都采用紧凑左右布局，目录与正文不设独立滚动区；正文过长仍需自然纵向滚动。文档路径是分类，不代表DOCX文件落盘路径。

验证：106项服务端测试，包括目录创建去重、非法路径、权限、文档移动、并发冲突、历史恢复；桌面和网页构建通过。上线前备份 `wiki_pages`、`wiki_page_versions`、目录及迁移记录。数据库迁移只新增目录表、路径列和索引，不删除历史数据。
