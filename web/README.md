# 第二期 · 手机任务工作台

独立 H5 仓库，TypeScript strict + React 18 + Ant Design Mobile。构建部署路径 `/h5/`，同域 `/api`。本目录只管理网页端，不修改旧桌面数据库。

## 当前访问方式（用户最新决定）

网页使用服务器 `WEB_ACCESS_PASSWORD` 配置的固定访问密码，无账号、无进入公司选择；App 免密策略由桌面仓库负责。网页从 `/auth/access-mode` 读取 `web_password_required`，开启时仅显示密码框，`POST /auth/enter {client:"web",password}` 成功后进入两公司共享工作台。真实密码不进入源码、测试或浏览器持久化，表单提交后清空。401 或两小时到期后重新输入密码，不自动保存/重放密码，也不使用旧刷新 Cookie。未要求网页密码时才启用原公开自动进入；关闭公开模式时保留旧账号登录。

公司仍为单据内的归属字段，工作台共享两家公司数据。下面“公开模式”描述的数据共享范围不变，但自动进入只适用于 `web_password_required=false`，本节覆盖早期免密网页说明。

## 已实现

- 用户已明确选择两公司共享模式：读取 `/auth/access-mode` 后，按配置验证固定网页密码再进入工作台，没有账号或进入时公司选择；任务表单内选择归属公司，默认 tmy，编辑保留原公司，列表/详情标注归属。公开模式目录共享，不按公司过滤部门、员工和分类。关闭公开模式后仍保留原账号登录与首登改密。
- Access Token 只在内存。共享模式不携带 Cookie、不调用 refresh，不显示账号、改密或退出入口；要求网页密码时会话到期回密码页；仅无密码配置下才自动 enter 重试一次。非公开账号模式继续使用 HttpOnly Cookie 刷新。
- 月份、明确的「全部」业务分类、部门、执行人、六状态、优先级、标题关键词筛选；服务端分页、下拉刷新、加载更多；移动端横向看板。
- 管理员手动新建/编辑/删除任务；员工只展示任务列表与详情、状态推进。状态只逐步前进或取消，取消不可重开。
- 交付时间精确到分钟；业务分类、任务类型与部门独立；部门变更清空执行人，执行人只从该部门在职员工选取。
- AI 粘贴文本识别草稿，采用服务端返回的公司、部门及分类推荐；显示公司匹配原因，操作员可改公司，保存最终 company_code 供服务器识别真实纠正。执行人始终人工选择，逐项校对保存；匹配元数据不提交任务接口。
- 「任务汇总」卡片及详情显示已关联送货单数量；点击弹窗查看单号、日期、归属公司及草稿/正式状态。H5 仅查看摘要，开单和打印在 App 完成。
- 任务图片只读缩略图，点击全屏多图滑动/缩放预览。图片增删、送货单、打印、Excel 不属于 H5 范围。
- 部门、员工、业务分类新增/编辑/删除；在职/离职状态；关联删除保护显示后端错误。
- 浏览器网络事件与每 30 秒健康检查；断网禁写、仅保留当前页面内存中的显示内容。不提供离线登录、离线修改、IndexedDB 或 Service Worker。
- 所有 API JSON 通过 Zod 校验；数字主键为 string；日期不仅检查格式，也检查真实日历合法性。

## 实施状态与边界

1. 共享状态已按用户澄清采用 **RxJS 7 + action/reducer + scan**：认证令牌与用户、任务筛选、基础资料、联网状态在单个 store 管理；React 表单临时输入留在局部。换公司/退出清除旧公司数据，令牌只驻内存。
2. 已经用户明确授权，在实际指定实例完成 H5 只读登录与任务/部门/员工/分类页面读取验证（2026-09-22）。未在此测试写删远端数据；服务器私有磁盘附件缩略图、原图和放大已在用户授权后验证；AI真实调用结果见总工程记录。单元和本地 UI 测试使用可控模拟响应。
3. 切换页面会卸载当前表单与未保存 AI 草稿；关闭页面也不会持久化草稿。没有后台自动保存。
4. 看板卡片按分页加载，列头总数来自当前筛选各状态的服务器 total，并明确显示已加载量。基础资料选择器逐页读取全部数据。六状态计数为并发查询，多人同时修改时可能出现短暂统计时间差。
5. 已签名图片 URL 由服务端提供；过期后重新打开详情获取新 URL。私有附件存储未配置会明确失败，不使用模拟图片兜底。
6. 没有用户开户管理界面；管理员账号由服务端初始化，员工账号权限关联须由服务器维护。

## 本地运行

要求 Node.js 22.12+，可访问后端 `http://127.0.0.1:3000`。

```sh
npm ci
npm run dev
# 打开 http://127.0.0.1:5175/h5/
npm run typecheck
npm test
npm run test:ui
npm run build
```

`vite.config.ts` 将 `/api` 代理到本机 3000；本地 HTTP 调试仅在隔离测试环境设置后端 `COOKIE_SECURE=false`。生产必须 HTTPS 与 Secure Cookie。构建产物为 `dist/`，Nginx 应将 `/h5/*` 深链接 fallback 到 `/h5/index.html`，`/api/*` 转发服务器。无客户端密钥或 AI API Key。

`npm run test:ui` 默认使用本机 Chrome，模拟 iPhone 13 尺寸，不依赖私有生产账号。CI 未安装 Chrome 时需安装 Chrome 或调整 Playwright 的浏览器 channel。
