H5 `CLOUD_E2E=1 npm run test:cloud` 只限用户明确授权的指定服务器与测试账号，读取受保护交接文件；不开截图、trace、视频，不输出密码。当前配置使用正常 TLS 校验。该测试不创建、修改或删除业务数据。

服务器真实写入测试、旧库迁移与恢复各有不同副作用和范围；不能通过执行只读测试来宣称这些动作已完成。所有凭据留在受保护文件中，不写入本验证记录。
